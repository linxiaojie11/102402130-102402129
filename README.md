# 校园失物招领 · 程序实现

2026 秋软件工程第二次结对作业，基于仓库内的 HTML 原型实现。采用原生 HTML / CSS / JavaScript，无框架、无外部字体和 CDN，Chrome 双击 `index.html` 即可运行。

## 快速运行

1. 下载完整仓库并解压，保留目录结构。
2. 在 Google Chrome 中打开根目录 **index.html**，无需安装 Node、Python，也无需启动服务器。
3. 初次运行会显示 10 条虚构示例（8 条进行中、2 条已完成）；示例联系方式不能用于真实联系。
4. 点击“发布”，选择寻物 / 招领，填写名称、地点、联系方式；时间、描述选填。
5. 首页可组合筛选类型、类别、地点和状态；搜索支持名称、地点、类别及描述，忽略首尾空白和英文大小写。
6. 点击信息卡片查看详情，可复制联系方式，再通过提供的方式在站外联系。
7. 发布者在“我的发布”或自己的详情页点击“标记已找到” / “标记已归还”，确认后结束信息；也可重新开启。已完成信息默认退出首页进行中列表，在状态筛选及搜索中仍可看到结果。
8. “我的发布”支持编辑信息和 JSON 备份导出 / 导入。

## 数据与权限范围

本项目是符合直接打开 HTML 要求的**本地演示程序**。所有记录和本机发布者标识保存在 Chrome `localStorage`，刷新可保留；不同设备、Chrome 用户配置或网页地址之间不保证共享。请使用同一位置的 `index.html`，同一时间用一个标签页编辑。清除浏览器站点数据会丢失记录和本机身份，重要数据先导出备份。

“我的发布”依据本机随机发布者标识判断，普通界面只能修改自己的信息。这个标识不是登录认证，也不能防止持有本机开发者工具的人篡改数据。示例信息属于示例发布者，不可编辑。要做真实全校共享服务，需要另行实现服务端、账号认证及持久化数据库。

备份导入只合并未存在的 ID，不覆盖已有记录，不接管其他发布者身份。在原浏览器导回自己的备份可继续管理；在新浏览器导入可浏览这些信息，但不能修改原发布者记录。文件包含公开联系方式，应自行保管。支持最多 2000 条记录和 2 MB 导入文件。损坏文件、未知版本、非法字段和重复 ID 会被拒绝。

本地存储被禁用、数据损坏或容量已满时，会显示错误且不会提示保存成功；保存失败会保留填写内容。启动时发现损坏数据不会自动覆盖原数据。可先在 Chrome 开发者工具 Application → Local Storage 保留原值，再排查对应键 `campus-lf-v1`，必要时手动清除该键并刷新（会重建示例及身份）。
