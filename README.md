# 校园失物招领小程序（交互原型）

一个用 **单文件 HTML + 原生 JS** 实现的校园失物招领交互原型。无需安装任何环境，浏览器打开即可演示完整的失物招领流程。

## 功能一览

| 功能 | 说明 |
|---|---|
| 浏览信息 | 首页展示进行中的失物 / 招领信息，按发布时间倒序排列 |
| 筛选信息 | 可按「寻物 / 招领」类型、物品类别、地点三重筛选 |
| 发布信息 | 发布寻物 / 招领启事，含分类、地点、时间、描述、联系方式 |
| 搜索信息 | 关键词搜索（匹配名称、地点、分类、描述），结果关键词高亮 |
| 查看详情 | 点击卡片进入详情页，查看完整信息与联系方式 |
| 编辑信息 | 「我的发布」中可修改自己发布的信息并保存 |
| 状态管理 | 可将自己的信息标记为「已解决」，已解决信息自动从首页与搜索结果移除 |

## 运行方式

1. 直接双击 `校园失物招领小程序.html`，用任意现代浏览器（Chrome / Edge / Firefox）打开；
2. 无需安装、无需联网、无需启动服务器；
3. 页面自带 10 条示例数据（8 条进行中、2 条已解决）；你发布、修改的信息会保存在浏览器本地（localStorage），刷新不丢失；
4. 想恢复初始示例数据：在浏览器地址栏执行 `localStorage.clear()` 后刷新页面即可。

## 操作指南（四条演示流程）

**流程一 · 查找失物**：进入首页 → 浏览或筛选（类型 / 类别 / 地点）→ 点击卡片查看详情 → 复制联系方式联系发布者。

**流程二 · 发布信息**：点击底部「＋发布」→ 选择类型（寻物 / 招领）→ 填写物品名称、分类、地点（可点快捷地点）、描述、联系方式 → 点击「确认发布」→ 首页立即出现。

**流程三 · 搜索信息**：点击顶部搜索框或底部「搜索」→ 输入关键词（或点热门词）→ 查看高亮搜索结果 → 点击查看详情。

**流程四 · 管理自己的信息**：进入「我的发布」→ 点击「编辑修改」改内容并保存，或点击「标记已解决」→ 该信息从各列表移除。

## 附加特点（评分加分项）

1. **按物品类别筛选**：首页提供 6 大类别（卡证证件 / 数码设备 / 生活用品 / 书籍资料 / 衣物配饰 / 其他）快捷筛选，每类有专属颜色标识；
2. **按地点筛选**：首页地点下拉框自动汇总所有发布地点，可一键筛选指定地点；
3. **一键复制联系方式**：详情页「复制联系方式」按钮，点击即复制，方便联系发布者；
4. **复制失物信息分享**：详情页「复制失物信息」按钮，一键生成格式化文本，可粘贴到班级群 / 朋友圈扩散；
5. **快捷地点填写**：发布页提供常用地点（图书馆 / 食堂 / 教学楼等）一键填入；
6. **首页数据统计**：顶部实时显示「进行中 / 已解决 / 我的发布」数量；
7. **相对时间显示**：列表自动显示「刚刚 / X 分钟前 / X 小时前 / X 天前」；
8. **搜索结果关键词高亮**：匹配词高亮显示，一眼定位命中位置。

## 单元测试

原型逻辑内嵌在 HTML 中，为保证可测试性，将纯函数抽取到 `tests/core.js`（`esc`、`typeText`、`statusText`、`relTime`、`buildShareText`、`homeFilter`、`searchMatch`），页面与测试共用同一份逻辑。

```bash
# 需要 Node.js 18+
node --test tests/core.test.cjs
```

当前 **22 个用例全部通过**，覆盖：

- HTML 转义（`& < > " '`、null / undefined 容错）；
- 相对时间边界（1 分钟内、刚好 1 分钟、X 分钟 / 小时 / 天前、超过 7 天回退为 MM-DD）；
- 组合筛选（类型 × 类别 × 地点、已解决一律排除）；
- 关键词搜索（命中标题 / 地点 / 分类 / 描述、英文大小写不敏感、空关键词与首尾空白）；
- 分享文本生成（寻物 / 招领、无描述省略、时间为空显示「未填写」）。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，**零外部依赖**（无 CDN、无框架），离线可用；
- 示例数据在 `assets/data.js` 的 `window.LF_SEED` 中，可自行增删改；
- 用户发布的数据保存在浏览器 `localStorage`（键 `lf_proto_items_v2`，读取带容错，损坏时自动回退示例数据）；
- 界面按手机小程序风格设计，桌面浏览器打开时居中显示，移动端自动铺满屏幕；
- 单元测试使用 Node 内置 `node:test`，无第三方依赖。
